The Russian Empire in Color

Colorizing the Prokudin-Gorskii glass-plate collection via alignment.

lucas zheng · github.com/3LucasZ/cs180-showcase · P1 source code

Problem

I am very thankful to Prokudin-Gorskii for taking these glass plate images. We can realize what the Russian Empire looked like in the past. The glass plates correspond to Blue, Green, and Red. However, if you try to place the plates on top of each other, it looks really off.

We need an algorithm to align them. This will take some experimentation. They seem to be rotated correctly, so we will shift each image x, y to align.

Naiive idea

We perform our alignment algorithm twice: align green to blue first, then align red to blue. Then, all 3 glass plates will be aligned as a single image. The most natural, naiive idea is to align an image with another image via brute force search over every single possible (x,y) shift alignment. This will take very long if we try every single shift. Luckily, it doesn't seem like we have to shift too much, from our example above. For a small image with a small shift like our example above, it suffices to just check shifts in the x and y direction within [-32, 32] pixels.
