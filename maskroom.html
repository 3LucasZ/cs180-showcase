maskroom

Load two images

A scene to blend into, and an object to cut out of. Then draw the mask, drop the object into the scene, and take the files.

Mask tool

48 px
0 px

The object is cut out where the mask is white. Feather softens that edge — the multiresolution blend can handle a hard edge, but a few pixels of softness kills the seam halo.

Placed object

Drag the object to move it, corners to size it, the stem to turn it. Hold shift on a corner to keep the proportions.

Output files

—

scene, object, mask and composite come out at one size, so they line straight up in your blend — the picture to blend into, the object image whole, the mask white exactly where it sits, and the object already placed on the scene. They are written as one set so the sizes cannot drift apart. object keeps the whole image rather than just the part inside the mask: a cropped object puts a dark edge at the seam, which the blend smears into a ring. It is a PNG because the space around the object is left transparent, not black. composite is a plain alpha preview, not the multiresolution result.
